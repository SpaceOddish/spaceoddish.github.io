# Make your own AO3 wrapped!

If you use bookmarks to track your reading in any capacity and would like to get nice stats and plots almost instantly—this little spreadsheet is for you!

It's a modified version of my own (very messy) Google Sheets spreadsheet that I used until earlier this year. I talk about that spreadsheet and some of the formulas used there [here](https://spaceoddish.github.io/post/ao3-bookmarking/).

It is built so that it needs very little input to provide the basic stats and charts.

[Here's the link to the repo](https://github.com/SpaceOddish/ao3-wrapped-spreadsheet.git). All the details in the README file.
